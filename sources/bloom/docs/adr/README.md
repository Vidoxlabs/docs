# Architecture decision records

Architecture decision records for Bloom live in this directory and follow the [hub ADR convention](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/README.md) and [ADR template](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/template.md).

ADRs are named `NNNN-<slug>.md` and numbered sequentially starting from `0001`. Agents author ADRs with status `Proposed`; only an owner decision moves an ADR to `Accepted`.

The planned `docs/adr/0001-terminal-renderer.md` (covering terminal rendering without a third-party TUI library, open under decision `D12` in [CAP-10](../capabilities/CAP-10-trace-observability.md)) keeps number `0001`.
