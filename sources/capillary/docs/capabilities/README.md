# Capabilities

This directory holds `capillary`'s capability ledger (`index.json`) and lead capability specifications.
The shared family timeline, roadmap, and specification template live in [Vidoxlabs/docs](https://github.com/Vidoxlabs/docs/blob/main/docs/timeline/README.md).
Any pull request that adds, changes, advances, or lands a capability slice must update `docs/capabilities/index.json`, the owning specification's Evidence and Changes sections, `docs/CHANGELOG.md`, and any touched contract's Changes section in the same pull request.
