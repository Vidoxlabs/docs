# Capillary charter

## Mission

Give agent workspaces retrieval they can quote: sources recorded with their digests,
excerpts bounded by stated budgets, and relations between context items that stay typed
and inspectable — so a conversation, a run, or a reviewer can always ask *where did this
context come from, what was it, and what was cut*.

Capillary is the context-retrieval member of the botanic family: the fine-channel system
that lifts context to the workspace that needs it. Where bloom is the opened team
workspace and seed is the growth layer beneath it, capillary decides nothing — it
retrieves, bounds, and organizes.

## Principles

1. **Provenance or it is not context.** Every item capillary admits to a packet carries a
   source reference and a digest. Untethered prose does not enter.
2. **Declared truncation.** A shortened excerpt is marked shortened, with the size
   carried and the size cut. A omitted-for-budget item is recorded as omitted, not
   silently dropped.
3. **Bounded recall.** Every packet carries its budgets. What arrives matches them or
   the packet says why not.
4. **Unknown stays unknown.** A source that could not be read or verified stays unknown;
   it is never reported as "no results" and never substituted with plausible content.
5. **Retrieval is not remembering.** Capillary holds sources and relations, not consent.
   Remembering with consent and forget belongs to the memory fabric. Retrieving into a
   run is an admitted, recorded intent — never an ambient memory grab.
6. **Relations are typed and append-only.** Context organization is an event history:
   records are added, never rewritten in place.

## Non-goals

- Not a chat log, not a transcript store, not a memory of conversations.
- Not a black-box similarity dump: relevance signals are stated, not implied.
- Not a network crawler: anything that reaches outside the local process ships as an
  adapter behind a contract, never an assumption.
- No silent coupling to any single store format. The contracts are the interface.

## Standing constraint

The first consumers already proved the operating shape: a team's evidence budget lands
whole, bounded excerpts per file with an honest "shortened" marker on the ones that were
cut. Those numbers (28,000 characters across a packet, 12,000 per item) are capillary's
family baseline defaults; a caller's budgets, where stated, always win.
