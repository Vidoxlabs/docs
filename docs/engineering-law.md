# Engineering law

The discipline shared by the public Vidoxlabs repositories, kept here in one page and linked from the family.

- License: MIT, exact text, one copy per repository, no riders.
- Dependencies: zero at runtime. A dependency proposal is an architecture decision before it is a package.
- Runtime: Node 22.13 or newer. `npm test` stays green on every commit.
- Claims: every capability carries `implemented`, `specified`, `planned`, or `observed`, and the label must be true.
- Unknowns fail closed: a missing head, a failed fetch, or an unreadable source stops the work. Nothing is guessed, filled in, or reported as empty when it is unknown.
- Public safety: no credentials, tokens, account names, personal handles, hostnames, IP addresses, port numbers, container names, cluster names, or network topologies in any committed file.
- Text only: documentation pages and synced sources stay text. No binaries enter this hub.
- Prose: short plain sentences, noun-led lines, no invented product names, no em-dashes anywhere.
