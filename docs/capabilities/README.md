# Docs capabilities

This folder holds the hub's local capability ledger (`index.json`) and lead capability specifications (`CAP-NN-<slug>.md`).
Cross-repository milestones, dependencies, and the family ledger live in [the timeline guide](../timeline/README.md).
Same-PR ledger rule: every capability or contract PR updates `index.json`, the owning spec's `Evidence` and `Changes` sections, `docs/CHANGELOG.md`, and touched contract `Changes` sections in the same PR.
