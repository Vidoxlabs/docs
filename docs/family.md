# The family and this hub

The public products grow from botany: seed, capillary, myosotis, aestivation, drosera, and bloom, with trellis standing outside the call path to probe them. The naming law, the stack, and the reason the line is botanic live in [capillary's docs/family.md](https://github.com/Vidoxlabs/capillary/blob/main/docs/family.md).

This repository is plain-named by owner decision, as `videsign` is: infrastructure carries plain words, and the botanic line stays for products. The hub serves the whole family. It writes the shared pages once, and it carries each member's own documentation verbatim, with digests and heads, so a reader or a site can trust exactly what landed and when.

Per-source documentation lands under `sources/<name>/` as written upstream. The hub formats nothing, edits nothing, and resolves no conflicts between sources: a disagreement between two repositories' pages stays visible until the owner settles it upstream.
