# The family and this hub

Vivarium is the product. Its seven systems take their names from botany: seed, capillary, myosotis, aestivation, drosera, and bloom, with trellis standing outside the call path to probe them. `bloom` is Vivarium's user interface, one system among the seven, not the product. The `vivarium` repository pins the seven at exact commits. The naming law, the stack, and the reason the line is botanic live in [capillary's docs/family.md](https://github.com/Vidoxlabs/capillary/blob/main/docs/family.md).

This repository is plain-named by owner decision, as `videsign` is: infrastructure carries plain words, and the botanic line stays for the systems. The hub is product-neutral: Vivarium does not pin it, and it may serve later products. It serves every public repository it syncs. It writes the shared pages once, and it carries each member's own documentation verbatim, with digests and heads, so a reader or a site can trust exactly what landed and when.

Per-source documentation lands under `sources/<name>/` as written upstream. The hub formats nothing, edits nothing, and resolves no conflicts between sources: a disagreement between two repositories' pages stays visible until the owner settles it upstream.
